## 1. 요구사항 분석

기획서 PPTX(기존 화면 스크린샷 4종 + 디벨론 공식 브랜드 가이드)를 분석해 확정한 사양:

- 기존 화면 구조(사이드바 필터·KPI·지역별 오픈 현황·그룹별 성과·결과 분석·클릭 심층 분석·월별 추이·ALL 비교) 유지하며 업그레이드
- 신규 요구: ① 브랜드별 디자인 가이드 적용(현대/디벨론) ② 세계지도 지역별 오픈율 ③ 결과 분석 AI 자동 기입 ④ 엑셀 업로드만으로 자동 반영 ⑤ 여백 등 디자인 완성도

## 2. 설계 결정

| 결정 | 이유 |
|---|---|
| CSS 변수 기반 브랜드 테마 6종 (현대/디벨론/ALL × 라이트/다크) | 디벨론 공식 가이드(#FF5F00·Charcoal #161616·Exo 폰트, 보조색 단독 사용 금지) 준수. 브랜드 셀렉트 전환 시 자동 적용 |
| 세계지도 = 인라인 SVG 실루엣 + 지역 버블(크기=수신자, 농도=오픈율) + 순위 막대 병행 | 외부 지도 라이브러리 없이 안정 동작, 도넛 게이지 그리드와 탭 전환 |
| 결과 분석 = 규칙 기반 5종 자동 생성 (01~05 형식) + LLM 어댑터 지점 문서화 | API 키 없이 항상 동작, 사내 정책 확정 시 LLM으로 고도화 |
| 엑셀 3시트 양식 + 유사 컬럼명 매핑 + 행 검증 리포트 | "매번 코딩 없이 업로드만으로 업데이트" 요구 충족 |
| 브랜드 비교색(현대 파랑 vs 디벨론 오렌지)은 색각 검증 통과 조합 | 기존 화면의 색 관례 유지 + 접근성 |
| 라이브러리(SheetJS·Chart.js) 로컬 동봉 | CDN 미의존 (Exo 폰트만 Google Fonts, Arial/Noto Sans KR 폴백) |

## 9. 2026-08-29 DEVELON 브랜드 컬러 재검토 (대표 지시: "디벨론일 때 전체 컬러도 다시 고려")

**발견 1 — 진짜 컬러 버그(전체 화면에 영향)**: `body.hd.hd-app`가 공통 레이어 `hd-theme.css`의
`background: var(--hd-bg)`(특정도 0,2,1)를 타는데, style.css의 `body{background:var(--bg)}`(0,0,1)보다
특정도가 높아 항상 이겼다. `--hd-bg`는 `[data-theme]`/OS 다크설정만 보고 이 프로젝트가 실제로 쓰는
`[data-mode]`/`[data-brand]`는 전혀 모름 — 그래서 DEVELON·다크를 선택해도 배경이 계속 밝게 남아 있었다.
`.card`/`.btn`/`table` 등 hd-theme.css가 건드리는 요소 전부 같은 문제였을 것으로 추정.
→ **`css/theme-bridge.css` 신설**(hd-theme.css는 그대로 두고 §5.3대로 맨 뒤에 덮어쓰기 레이어만 추가) —
`--hd-*` 토큰을 이 프로젝트의 `--bg`/`--surface`/`--primary` 등에 별명 붙여 브랜드/모드 전환에 자동으로
따라오게 함. playwright로 DEVELON 라이트·다크 둘 다 스크린샷 재확인 — Charcoal 배경/Off-white 배경 정상 렌더링.

**발견 2 — 공식 컬러 드리프트**: `--c-develon`/`--c-main`이 다크 계열 4곳(ALL·Dark, HYUNDAI·Dark,
DEVELON·Dark 자신)에서 공식 Main(`#FF5F00`)이 아닌 `#F05800`으로 되어 있었음(같은 DEVELON·Dark 블록
안에서 `--primary`는 FF5F00인데 `--c-develon`만 F05800로 갈라짐 — 의도된 보정이라 보기엔 차이가 6~7%뿐이라
근거 없음, 드리프트로 판정). 전부 `#FF5F00`으로 통일.

**발견 3 — 접근성 위반 2건 (DEVELON·Light)**:
- `--focus: #E73B00`(Onward Orange)는 브랜드 가이드가 "보조색·단독 사용 금지"로 못박은 색인데
  focus 링(단독 강조 용도)에 쓰이고 있었음. `--primary`(FF5F00)로 바꿔도 페이지 배경(#E1E3E4) 대비
  2.37:1로 3:1 기준 미달 → **Charcoal(#161616)**로 교체, 대비 14.05:1.
- `--primary-ink: #ffffff`가 브랜드 오렌지(FF5F00) 위에서 3.05:1 — 일반 텍스트 기준(4.5:1) 미달.
  탭 활성 버튼·태그·데이터 업로드 버튼 텍스트 전부 영향. **Charcoal(#161616)**로 교체, 대비 5.94:1.
  두 값 모두 실제 렌더링에서 `getComputedStyle`로 `rgb(22,22,22)` 적용 확인.

**유지한 것**: 색상 램프(단일 색상 계열, 색약 안전) 4단, `--up`(Eco Green 파생 어두운 톤 — 리터럴
보조색 자체를 쓰는 게 아니라 파생 변형이라 "단독 사용 금지" 규정 위반으로 보기 어려움)은 그대로 둠.
