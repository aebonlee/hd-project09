## 1. 요구사항 분석

기획서 PPTX(기존 화면 스크린샷 4종 + 디벨론 공식 브랜드 가이드)를 분석해 확정한 사양:

- 기존 화면 구조(사이드바 필터·KPI·지역별 오픈 현황·그룹별 성과·결과 분석·클릭 심층 분석·월별 추이·ALL 비교) 유지하며 업그레이드
- 신규 요구: ① 브랜드별 디자인 가이드 적용(현대/디벨론) ② 세계지도 지역별 오픈율 ③ 결과 분석 AI 자동 기입 ④ 엑셀 업로드만으로 자동 반영 ⑤ 여백 등 디자인 완성도

## 2. 설계 결정

| 결정 | 이유 |
|---|---|
| CSS 변수 기반 브랜드 테마 6종 (현대/디벨론/ALL × 라이트/다크) | 디벨론 공식 가이드(#FF5F00·Charcoal #161616·Exo 폰트, 보조색 단독 사용 금지) 준수. 브랜드 셀렉트 전환 시 자동 적용 |
| 세계지도 = 인라인 SVG 실루엣 + 지역 버블(크기=수신자, 농도=오픈율) + 순위 막대 병행 | 외부 지도 라이브러리 없이 안정 동작, 도넛 게이지 그리드와 탭 전환 |
| 결과 분석 = 규칙 기반 5종 자동 생성 (01~05 형식) + LLM 어댑터 지점 문서화 | API 키 없이 항상 동작, 사내 정책 확정 시 LLM으로 고도화 |
| 엑셀 3시트 양식 + 유사 컬럼명 매핑 + 행 검증 리포트 | "매번 코딩 없이 업로드만으로 업데이트" 요구 충족 |
| 브랜드 비교색(현대 파랑 vs 디벨론 오렌지)은 색각 검증 통과 조합 | 기존 화면의 색 관례 유지 + 접근성 |
| 라이브러리(SheetJS·Chart.js) 로컬 동봉 | CDN 미의존 (Exo 폰트만 Google Fonts, Arial/Noto Sans KR 폴백) |

## 3. 구현 내역

- 사이드바 필터(브랜드/월 자동 생성/대상/지역 12개, 전체선택·해제) — 모든 화면 요소 즉시 반영
- KPI 4종(총 발송·오픈·평균 오픈율·클릭, 전월 대비 ▲▼)
- 세계지도(버블 12개, hover 상세) ↔ 도넛 게이지 탭, 지역 오픈율 순위 막대
- 그룹별 성과 표(ALL에서 브랜드 행 추가), 콘텐츠 선호도 순위, 클릭 빈도 분포, VIP 독자 Top5(가상 이메일)
- 월별 오픈율 동향(Hyundai vs Develon 라인 + 발송건수 콤보 패널), ALL 브랜드 비교 grouped bar 2종
- 결과 분석 자동 기입(최고 지역/전월 변화/모수 기여/저조 지역 제안/콘텐츠 시사점) + [복사]
- 엑셀 업로드(발송실적/콘텐츠클릭/독자클릭 3시트), 양식·샘플 xlsx(`make_samples.py`), 임베디드 데모 동일 데이터
- 내보내기: 차트 PNG, PDF 인쇄, 필터 결과 엑셀
