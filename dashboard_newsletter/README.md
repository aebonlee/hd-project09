# AMPS 뉴스레터 결과보고 대시보드

HD건설기계 AMPS기획팀의 글로벌 뉴스레터(HYUNDAI / DEVELON) 발송 성과를 한 화면에서 보고하는 단일 페이지 대시보드입니다.
서버 없이 **브라우저에서 `index.html`을 여는 것만으로 동작**하며, 엑셀 업로드만으로 데이터가 자동 반영됩니다.

## 1. 사용법

1. `dashboard_newsletter/index.html`을 브라우저(크롬 권장)로 엽니다. 첫 화면에는 내장 샘플 데이터(3~7월)가 표시됩니다.
2. 좌측 사이드바에서 필터를 조작합니다 — 모든 차트·표·인사이트가 즉시 반응합니다.
   - **브랜드**: All / Hyundai / Develon (선택 시 브랜드 테마로 자동 전환, All에서는 브랜드 비교 차트 3종 — 그룹별 오픈율(클러스터), 지역별 오픈율, 지역별 발송 비중(100% 스택) — 추가 표시)
   - **월별**: 데이터에 존재하는 월이 자동으로 체크박스로 생성됩니다.
   - **내부/딜러**: 내부직원 / 딜러
   - **지역** 12개: 본사, 중남미, 아프리카, 중동, 러시아/CIS, 아시아, 대양주, 터키/이스라엘, CNHI, 브라질, 인도네시아, 북미
3. 월별 동향 카드의 **[발송건수 콤보 표시]**를 켜면 오픈율 라인 위에 발송건수 막대가 이중 축 콤보 차트로 겹쳐집니다.
   그 옆 **월별 발송·오픈 구성** 카드는 오픈/미오픈을 스택 영역 차트로 보여줍니다 (합계 = 발송).
4. 지역별 현황은 **세계지도 ↔ 도넛 게이지** 탭으로 전환할 수 있습니다. 지도 버블은 크기=수신자 수, 색 농도=오픈율이며 마우스 오버 시 상세 툴팁이 표시됩니다.
5. 우상단 메뉴(☰): 엑셀 업로드 · Light/Dark 테마 토글 · PNG 저장(차트별) · PDF 인쇄/저장 · 필터 결과 엑셀 다운로드.
   - PDF는 브라우저 인쇄 대화상자에서 "PDF로 저장"을 선택하세요(인쇄 전용 CSS 적용).
   - 전체 화면 캡처가 필요하면 PDF 인쇄를 이용하세요. PNG 저장은 캔버스 차트를 개별 파일로 내려받습니다.
6. **[샘플 데이터]** 버튼: 업로드 데이터를 버리고 내장 샘플로 되돌립니다.
7. 결과 분석(AI 자동 기입) 카드의 **[복사]** 버튼으로 보고서 본문에 붙여넣을 텍스트를 복사할 수 있습니다.

### 샘플 데이터 재생성

```bash
python3 make_samples.py   # openpyxl 필요
```

- `templates/뉴스레터_업로드양식.xlsx` — 업로드 양식(헤더 + 작성안내 시트 + 예시 2행)
- `templates/뉴스레터_샘플데이터.xlsx` — 3~7월 · 2개 브랜드 · 12개 지역 샘플
- `js/sample-data.js` — 동일 데이터를 브라우저에 임베드(자동 생성 파일, 직접 수정 금지)

### 테스트

```bash
node test/data.test.js    # 데이터 계층 단위 테스트 (필터 집계 / 오픈율 / 컬럼 매핑 / 인사이트)
```

## 2. 엑셀 업로드 양식

시트 3개 구성이며 **발송실적 시트만 필수**입니다. 시트명·컬럼명은 유사 표기(공백, 영문, '오픈 수' 등)를 자동 인식하고,
업로드 후 매핑 결과와 검증 오류·경고를 팝업으로 안내합니다. 오류가 있는 행은 해당 행만 제외됩니다.

### 시트1 `발송실적` (필수)

| 컬럼 | 설명 / 허용 값 |
|---|---|
| 월 | `3`, `3월`, `2025-03` 모두 인식 |
| 브랜드 | HYUNDAI / DEVELON (Hyundai·현대, Develon·디벨론 표기 허용) |
| 대상 | 내부직원 / 딜러 (내부, 직원, Dealer 등 허용) |
| 지역 | 위 12개 지역명 (러시아→러시아/CIS, 유럽→CNHI 등 별칭 인식) |
| 수신자수 | 숫자 (쉼표·'명' 허용) |
| 오픈수 | 숫자, 수신자수 이하 |
| 클릭수 | 숫자 |

### 시트2 `콘텐츠클릭` (선택) — 월, 브랜드, 콘텐츠명, 클릭수
### 시트3 `독자클릭` (선택) — 월, 브랜드, 이메일, 클릭수

선택 시트가 없으면 해당 분석(콘텐츠 선호도, 독자 클릭 분포, VIP 독자)만 비표시됩니다.

## 3. 브랜드 테마 색상표

브랜드 선택 시 CSS 변수 기반으로 테마가 자동 전환되며, 메뉴의 Light/Dark 토글은 브랜드 테마 위에 명도만 반전합니다.

### HYUNDAI (기본 Light, 네이비/블루)

| 용도 | Light | Dark |
|---|---|---|
| 배경 | `#F0F3F8` | `#0C1424` |
| 강조(Primary) | `#16305E` | `#5B8DEF` |
| 차트 기본색 | `#2E5FA3` | `#5B8DEF` |

### DEVELON (기본 Dark, 공식 브랜드 가이드)

| 용도 | 값 |
|---|---|
| Main — Develon Orange | `#FF5F00` |
| 배경 — Charcoal | `#161616` |
| Gray 1-Slate / 2-Stealth / 3-Stone | `#393939` / `#636363` / `#C9C9C9` |
| 텍스트 — Off-white | `#E1E3E4` |
| 보조색(단독 사용 금지, 강조에만) | Onward Orange `#E73B00`, Eco Green `#D6F400`, Nova Blue `#ABC5FF` |
| 서체 | 영문 Exo(Google Fonts, 폴백 Arial) / 국문 Noto Sans KR·맑은 고딕 |

다크 배경 차트 마크는 명도 검증을 통과하도록 `#F05800`(오렌지) 등 미세 조정 스텝을 사용합니다.

### ALL (중립 + 브랜드 비교 고정색)

브랜드 비교 차트에서는 항상 **HYUNDAI 파랑(`#2E5FA3`/다크 `#5B8DEF`) vs DEVELON 오렌지(`#FF5F00`/다크 `#F05800`)** 고정 배색을 사용합니다
(색은 개체를 따르며 필터로 재배색되지 않음, 색각이상 대비 검증 통과).

## 4. 결과 분석 자동 기입 — 규칙 + LLM 어댑터 지점

`js/insights.js`의 `generateInsights()`가 **필터된 데이터만으로** 3~5개 문단을 생성합니다. 규칙:

1. **최고 오픈율 지역** — 1·2위 지역과 평균 대비 언급 (수신 3명 미만 극소 표본 지역은 순위 제외)
2. **전월 대비 변화** — 선택된 최근 월 vs 직전 월 오픈율 ±0.5%p 기준 상승/하락/유지 + 권장 조치
3. **수신 규모 대비 기여** — 최대 모수 지역의 전체 오픈 기여율과 평균 견인 여부
4. **저조 지역 제고 제안** — 평균의 70% 미만 지역 최대 2곳 + 개선 제안
5. **콘텐츠 클릭 시사점** — 클릭 1·2위 콘텐츠와 상단 배치 전략 제안

### LLM 어댑터 지점

현재 코드는 규칙 기반만 포함합니다. LLM으로 문장 품질을 높이려면 `js/app.js`의 `renderInsights()`에서
`INS.generateInsights(...)` 호출부가 유일한 접점입니다. 같은 인자
(`{ filtered, allSends, contents, filter }` — 집계 수치는 `NLData.totals/byRegion/momDelta`로 산출 가능)를
프롬프트에 담아 사내 허용 LLM API로 보내고, 응답을 `[{title, body}]` 배열로 파싱해 그대로 렌더링하면 됩니다.
API 실패 시 규칙 기반 결과로 폴백하는 구성을 권장합니다. (본 저장소에는 API 키·호출 코드를 포함하지 않습니다.)

## 5. 파일 구성

```
dashboard_newsletter/
├─ index.html            # 단일 페이지 (인라인 SVG 세계지도 포함)
├─ css/style.css         # 3개 브랜드 × Light/Dark 테마 변수
├─ js/data.js            # 데이터 계층 (정규화·컬럼 매핑·필터·집계, Node 테스트 가능)
├─ js/insights.js        # 결과 분석 규칙 엔진
├─ js/app.js             # UI·차트·지도·업로드·내보내기
├─ js/sample-data.js     # 임베드 샘플 (make_samples.py 자동 생성)
├─ make_samples.py       # 샘플/양식 엑셀 + sample-data.js 생성
├─ templates/            # 업로드양식.xlsx, 샘플데이터.xlsx
└─ test/data.test.js     # 단위 테스트
```

의존 라이브러리는 저장소에 동봉된 `../lib/xlsx.full.min.js`(SheetJS), `../lib/chart.umd.min.js`(Chart.js 4)만 사용합니다(CDN 불필요).

## 6. 한계

- 세계지도는 **단순화한 대륙 실루엣**입니다(지리적 정밀도 없음). 지역 버블 좌표는 `js/app.js`의 `REGION_POS` 상수로 조정할 수 있습니다.
- 오픈수·클릭수는 업로드된 집계값을 그대로 사용하며, 중복 오픈 제거 등 원시 로그 처리는 하지 않습니다.
- 콘텐츠클릭·독자클릭 시트는 지역/대상 정보가 없어 **월·브랜드 필터만** 적용됩니다.
- 월은 1~12 숫자로만 관리되어 연도를 넘는 데이터(예: 2025-12 vs 2026-01)의 "전월" 비교는 지원하지 않습니다.
- 전체 화면 PNG 한 장 저장은 외부 라이브러리 없이 구현하지 않았습니다 — PDF 인쇄를 사용하세요.
- 결과 분석은 규칙 기반 문장으로, 데이터에 없는 맥락(캠페인 이벤트 등)은 반영하지 못합니다.
- 데모 데이터의 이메일 주소는 전부 가상(`*@example.com`)입니다. 실제 개인정보 취급 시 사내 보안 정책을 따르세요.
